Step 3: Validation Rules

Go to:

Employee → Validation Rules → New
1. Employee Name Validation

Rule Name:

EmployeeNameValidation

Formula:

OR(
    ISBLANK(Name),
    LEN(Name) < 3
)

Error Message:

Employee Name must contain at least 3 characters
2. Employee ID Validation

Rule Name:

EmployeeIDValidation

Formula:

Employee_ID__c <= 0

Error Message:

Employee ID must be greater than 0
3. Salary Validation

Rule Name:

SalaryValidation

Formula:

OR(
    Salary__c < 10000,
    Salary__c > 500000
)

Error Message:

Salary must be between 10,000 and 500,000
4. Email Validation

If Email field type is Email, Salesforce automatically validates email format.

No extra validation needed.

5. Department Validation

Rule Name:

DepartmentValidation

Formula:

ISBLANK(TEXT(Department__c))

Error Message:

Please select Department
6. Joining Date Validation

Rule Name:

JoiningDateValidation

Formula:

Joining_Date__c > TODAY()

Error Message:

Joining Date cannot be a future date
