Step 1: Create Student Object

Go to:

Setup → Object Manager → Create → Custom Object
Property	Value
Label	Student
Object Name	Student
Record Name	Student Name

Save.

Step 2: Create Student Fields

Go to:

Student → Fields & Relationships → New
Field Label	Type	API Name
Roll_Number	Number	Roll_Number__c
Marks	Number	Marks__c
Email	Email	Email__c
Step 3: Student Validation Rules

Go to:

Student → Validation Rules → New
Roll Number Validation

Rule Name:

RollNumberValidation

Formula:

Roll_Number__c <= 0

Error Message:

Roll Number must be greater than 0
Marks Validation

Rule Name:

MarksValidation

Formula:

OR(
    Marks__c < 0,
    Marks__c > 100
)

Error Message:

Marks should be between 0 and 100
Student Name Validation

Rule Name:

StudentNameValidation

Formula:

ISBLANK(Name)

Error Message:

Student Name cannot be blank
Step 4: Create Faculty Object

Create another custom object:

Property	Value
Label	Faculty
Object Name	Faculty
Record Name	Faculty Name

Save.

Step 5: Create Faculty Fields
Field Label	Type	API Name
Faculty_ID	Number	Faculty_ID__c
Salary	Currency	Salary__c
Email	Email	Email__c
Department	Picklist	Department__c
Joining_Date	Date	Joining_Date__c
Department Picklist Values
HR
IT
Finance
Marketing
Step 6: Faculty Validation Rules

Go to:

Faculty → Validation Rules → New
Faculty Name Validation

Rule Name:

FacultyNameValidation

Formula:

OR(
    ISBLANK(Name),
    LEN(Name) < 3
)

Error Message:

Faculty Name must contain at least 3 characters
Faculty ID Validation

Rule Name:

FacultyIDValidation

Formula:

Faculty_ID__c <= 0

Error Message:

Faculty ID must be greater than 0
Salary Validation

Rule Name:

SalaryValidation

Formula:

OR(
    Salary__c < 10000,
    Salary__c > 500000
)

Error Message:

Salary must be between 10,000 and 500,000
Email Validation

Rule Name:

EmailValidation

Formula:

NOT(
    CONTAINS(Email__c, "@")
)

Error Message:

Email must contain @ symbol
Department Validation

Rule Name:

DepartmentValidation

Formula:

ISBLANK(Department__c)
Error Message:

Please select Department
Joining Date Validation

Rule Name:

JoiningDateValidation

Formula:

Joining_Date__c > TODAY()

Error Message:

Joining Date cannot be future date
